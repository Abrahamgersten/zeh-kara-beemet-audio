# zeh-kara-beemet-audio

Audio files for the single-story pages of "זה קרה באמת" (https://abrahamgersten.github.io/zeh-kara-beemet/s/<slug>/).
Each recording with its ending: `links/<slug>-link.mp3` (any link) and `links/<slug>-status.mp3` (opened from a WhatsApp status).

A separate GitHub Pages site because a published Pages site may be at most 1 GB (Avraham approved, 2026-10-21).
Built by `רוני המתכנת/Tools/outros-2026-10-20/build_outros.py`; the pages link the files with `?v=<hash>`
(`זה קרה באמת/tools/build_story_pages.mjs`). Do not edit the files by hand.
